# Which fork type each Baystation 12 type becomes when port_map.py converts a Bay map or lists what it needs.
#
# A rule is a Bay type, then the fork type or "skip" with the reason:
#   /turf/simulated/wall/prepainted  /turf/closed/wall/bay/prepainted
#   /obj/overmap/*  skip  overmap
# A Bay type ending in /* also covers its subtypes; a fork type ending in /* then keeps the rest of the path
# (/obj/floor_decal/corner/red becomes /obj/effect/decal/bay_floor/corner/red), otherwise they all become that one
# type. The most specific rule wins. After the fork type, a rule may name var edits of the map to keep besides the
# ones every atom keeps (dir, pixel offsets, name, desc, color), as "var" or "bay_var>fork_var".
#
# A tile whose turf or area is dropped gets these:
@turf /turf/open/floor/plating/bay
@area /area/space
